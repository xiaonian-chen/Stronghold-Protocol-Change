# Stronghold Protocol Change v1.0

基于上游 [Stronghold Protocol v0.3.1](https://github.com/sganggs/Stronghold-Protocol/releases) 的集成改版，在保留上游核心玩法完整的前提下，新增多人扩展玩法、角色增强、游戏模式等功能。

---

## 集成功能一览

| 功能 | 类型 | 说明 |
|------|------|------|
| 20 人房间 | 玩法扩展 | 房间容量扩展至 4/8/10/16/20 人，6 人以上自动分组 |
| 分组悬赏选择 | 环法扩展 | 6 人以上悬赏选择按分组独立进行，各组同时选择互不干扰 |
| 首领限伤开关 | 环法扩展 | 房主可实时开关首领 30 万单次受伤上限 |
| 赤刃明霄陈强制限伤 | 环法扩展 | 无论开关状态，赤刃明霄陈始终受首领限伤 |
| 禁用飞行开关 | 环法扩展 | 可禁用飞行类型敌方单位 |
| 联防随机化 | 环法扩展 | 联防帮手选择改为全随机 |
| 克莱门莎改版 | 角色增强 | 新增不屈、迅捷/突袭盟约，全局击杀叠层特质 |
| 克隆模式 | 游戏模式 | 所有玩家使用相同阵容，倾向盟约独立选择 |
| 重复策略模式 | 游戏模式 | 队友可选择相同策略盟约 |

## 快速开始

### 环境要求

- Node.js 18+（项目自带运行时，无需单独安装）
- 现代浏览器（Chrome / Edge / Firefox）

### 启动服务器

1. 双击 `启动服务器（信任插件）.bat`
2. 输入 `0` 启用测试房间，或输入 `1` 正常游玩
3. 浏览器打开 `http://localhost:3000`

### Mod 管理

启动后浏览器访问 `http://localhost:3000`，在房间界面可通过 Mod 管理器勾选/取消各 Mod：

- **20p** — 20 人房间 + 分组悬赏 + 限伤开关等
- **clementia** — 克莱门莎改版
- **clone** — 克隆模式
- **dupBand** — 重复策略模式

禁用所有 Mod 后游戏仍可正常运行（回退为原版 4 人模式）。

## 功能详细说明

### 一、20 人模式（20p Mod）

启用 20p Mod 后，在原版上游基础上新增以下功能：

#### 1. 房间容量扩展

原版上游房间固定 4 人。20p 扩展为 5 档可选容量：

| 人数 | 分组方案 |
|------|----------|
| 4 | 不分组（原版行为） |
| 8 | 4+4 |
| 10 | 4+3+3 |
| 16 | 4+4+4+4 |
| 20 | 4+4+4+4+4 |

6 人以上自动分组，每组共享独立牌库。

**使用方法**：房间界面「同盟席位」处选择人数（4/8/10/16/20）。

#### 2. 分组悬赏选择

原版上游所有玩家从同一组 3 个悬赏中依次选择。20p 在 6 人以上时改为：

- 每组独立随机 6 个悬赏选项
- 各组同时开始选择，互不干扰
- 界面顶部有分组按钮（如「A组 0/3」「B组 0/3」），点击可查看其他分组内容
- 各组下方显示选择顺序和当前选择者（闪烁 = 正在思考，绿色 = 已完成）
- 每名玩家 30 秒选择时间，超时自动随机选择
- 玩家进入悬赏界面默认显示自己所在分组

4 人时行为与原版一致（不显示分组 UI）。

#### 3. 首领限伤开关

原版上游首领始终受 30 万单次受伤上限。20p 新增开关：

- **开启（默认）**：首领单次受伤上限 30 万（原版行为）
- **关闭**：不设限伤，首领吃全额伤害
- **例外**：赤刃明霄陈（char_1050_chen3）无论开关状态始终受首领限伤

**使用方法**：房间界面「首领限伤」开关，仅房主可操作。

#### 4. 禁用飞行开关

原版上游敌方单位可能包含飞行类型。20p 新增开关：

- **开启（默认）**：禁用飞行类型敌方，敌方阵容不会出现飞行单位
- **关闭**：允许飞行类型敌方（原版行为）

**使用方法**：房间界面「禁用飞行」开关，仅房主可操作。

#### 5. 联防随机化

原版上游联防帮手按固定规则选择。20p 改为全随机选择，每位符合条件的玩家都有均等机会被选为联防帮手。

#### 6. 分组共享牌库

6 人以上时，同组玩家共享一个牌库，不同组牌库独立。商店刷新、购买从对应组的牌库中抽取。

### 二、克莱门莎改版（clementia Mod）

启用 clementia Mod 后，在原版上游克莱门莎基础上新增以下功能：

#### 1. 改版模式

在 DIY 界面选择克莱门莎时可切换：

- **原版/改版**：切换改版模式
- **迅捷/突袭**：选择额外盟约类型（仅改版模式下可选）

#### 2. 额外盟约

改版模式下，除原有阿戈尔盟约外，新增：

- **不屈盟约**（indomShip）
- **迅捷盟约**（swiftShip）或 **突袭盟约**（raidShip），二选一

战斗面板正确显示所有盟约（阿戈尔 + 不屈 + 迅捷/突袭）。

#### 3. 全局击杀叠层特质

改版模式下，克莱门莎获得全局击杀叠层特质：

- **非精锐**：每累计击败 3 个敌人，所属盟约各 **+1 层**
- **精锐**：每累计击败 3 个敌人，所属盟约各 **+2 层**

叠层计算方式：任意友方单位击杀敌方时，克莱门莎的全局击杀计数 +1（不需要克莱门莎本人击杀）。每 3 次击杀触发一次叠层，给克莱门莎自身所有已激活盟约加层。

特质栏描述在战斗中正常显示叠层效果。

### 三、克隆模式（clone Mod）

启用 clone Mod 后：

- 所有玩家使用相同的阵容（策略盟约相同）
- 每位玩家可独立选择倾向盟约
- 倾向盟约选择后，选择框正确显示所选盟约名称

**使用方法**：房间界面切换游戏模式为「克隆」。

---

### 四、重复策略模式（dupBand Mod）

启用 dupBand Mod 后：

- 队友可以选择和他人重复的策略盟约
- 原版上游不允许重复策略盟约选择

**使用方法**：房间界面切换游戏模式为「重复策略」。

### 五、插件工作台插件

项目包含 3 个基于上游插件工作台（Studio）的信任插件，随服务器自动加载：

#### 1. 局内聊天（plugin-chat）

在房间内和局内提供实时文字聊天功能。

**功能**：
- 房间内所有玩家可发送文字消息
- 消息以弹幕形式飘过游戏画面
- 支持展开聊天面板查看历史消息
- 内置频率限制（每人 0.5 条/秒，突发上限 3 条），防止刷屏
- 消息长度限制 200 字符
- 房间关闭后自动清理聊天记录

**使用方法**：
- 游戏画面左下角有聊天按钮，点击展开聊天面板
- 输入文字后按回车或点击发送
- 聊天按钮上有红色角标显示未读消息数
- 可切换弹幕开关（开/关弹幕显示）

#### 2. 大厅房间列表（plugin-roomlist）

在大厅界面展示所有公开房间的列表，方便玩家快速加入。

**功能**：
- 列出所有已公开的房间，显示房间号、房主、难度、模式、人数
- 点击房间卡片可快速加入（自动填入房间号）
- 房主可将自己的房间公开/取消公开
- 支持快速加入（随机加入一个有空位的公开房间）
- 面板可拖动定位，位置自动记忆

**使用方法**：
- 大厅界面左下角有房间列表按钮，点击展开面板
- 房主可在面板底部点击「公开房间」将自己的房间加入列表
- 其他玩家点击房间卡片或使用「快速加入」按钮加入房间

#### 3. 干员时装（plugin-skins）

为干员提供额外时装（皮肤）资源，替换头像和战斗立绘。

**功能**：
- 为多个干员提供额外时装资源（头像 + Spine 立绘）
- 时装在角色选择/DIY 界面可选
- 包含的干员时装（部分示例）：
  - 凯尔希：甜品大奖、悠然假日 HDm25
  - 陈：岁、售罄
  - 史尔特尔：as_1、witch_5
  - 浊心斯卡蒂：boc_4、迭代
  - 耀骑士临光：时代XVII
  - 琴柳：时代XXXIV、时代LVII
  - 灰烬：时代L
  - 焰影苇草：时代XXX、风雪过境VIII、珊瑚海岸XVII
  - 空：游戏时代III、岁
  - 归溟幽灵鲨：boc_6
  - 暮落：时代XXXII
  - 执法官：售罄、三丽鸥II
  - 银灰：ambienceSynesthesiaIV
  - 德克萨斯：时代VII、冬日 I
  - 及更多……

**使用方法**：
- 插件自动加载，在角色选择/DIY 界面可选已安装的时装
- 无需额外操作，时装资源由插件自动注入

## 上游更新

本项目基于 Git 管理上游更新，完整流程见 `描述文件/上游更新指南.txt`。

简要步骤：

```bash
cd Stronghold-Protocol
git fetch upstream --tags
git merge v0.3.x          # 合并上游新版本
# 解决冲突（如有）→ git add . ; git commit
```

然后检查 Mod 兼容性：

```bash
cd ..
node mod-framework/scripts/gen-patches.js 20p
node mod-framework/scripts/check-patches.js 20p
node mod-framework/scripts/gen-patches.js clementia
node mod-framework/scripts/check-patches.js clementia
```

## 已修复的问题

详见 `描述文件/功能适配经验.txt`，主要修复包括：

- 禁用所有 Mod 后启动崩溃（DEFAULT_SEATS 导出缺失）
- 克莱门莎 mod 内容丢失（onLoadData hook 缺失）
- 克隆模式倾向盟约选择不了（gameMode 白名单缺失）
- 首领限伤开关不生效（全链路断点修复）
- 克隆模式倾向盟约选择框文本不更新（affinityBondId 字段缺失）
- 克莱门莎战斗面板额外盟约不显示（_flags 透传链路 7 处修复）
- 克莱门莎 garrison 叠层不触发（INSTALLERS 安装器缺失）
- 悬赏界面默认分组优化（自动显示玩家所在分组）
