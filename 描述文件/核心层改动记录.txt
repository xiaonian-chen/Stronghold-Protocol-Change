  [16] public/sw.js — Service Worker fetch 重试机制【通用】
      原：cache miss 后直接 fetch(request)，失败即抛 TypeError
      改：3 次重试循环，重试时用 new Request(url, { cache: 'no-store' }) 绕过浏览器 HTTP 缓存
      原因：scene.bin 请求偶发 ERR_FAILED，一旦出现 F5 无法恢复（硬刷新才恢复）
            SW 层 fetch 失败无重试，一次瞬断导致整个页面生命周期内 3D 场景不可用
      影响范围：所有经过 SW 拦截的 /assets/ /fonts/ /media/ 请求

  [17] public/js/render/board3d/load.js — 场景加载重试机制【通用】
      改动 a) 新增 fetchWithRetry(url, opts, attempts=2) 函数
             fetchText / fetchJson / fetchBuffer 改用 fetchWithRetry，各 2 次重试
      改动 b) loadScenePack 拆分为 loadScenePackCore + 外层 3 次重试循环
             每次间隔 800ms×attempt 递增，失败后 sceneCache.delete 允许重试
      原因：SW 重试可能仍不够（SW 本身可能未激活或被绕过），页面层也需要独立重试
      影响范围：所有 3D 场景加载（scene.json + scene.bin + lightmap + textures）

  [18] server/http/files.js — .bin 文件不再压缩【通用】
      原：COMPRESSIBLE 包含 '.bin'，brotli/gzip 压缩二进制顶点数据
      改：从 COMPRESSIBLE 移除 '.bin'，.bin 文件以原始二进制传输
      原因：scene.bin 是二进制顶点缓冲（2.4MB），压缩收益极小但增加出错风险
            主机 localhost 支持 brotli，朋友 LAN IP 只支持 gzip — 如果 brotli
            压缩异常只有主机受影响，与用户报告的"主机失败朋友正常"一致

  [25] server/match/host/index.js — 版本主机 fork 继承父进程 --import 钩子【20p/clementia/clone/dupBand】
      原：fork(ENTRY, [], { execArgv: [`--max-old-space-size=${mb}`], ... })
          子进程只拿到内存上限，父进程 scripts/launch.mjs 的 --import（20p-loader.mjs 的
          模块解析钩子）不在其中 → 版本房间加载上游原版，mod overrides 全部失效
      改：新增导出 inheritedImportFlags(argv = process.execArgv) / importFlagValue(v)
          · 识别 --import x 与 --import=x 两种写法，缺值/后续是 - 开头的跳过
          · 路径经 pathToFileURL(path.resolve(v)) 转绝对 file:// URL；裸包名原样保留
          · kind === 'version' 的 fork 在 execArgv 末尾追加 ...inheritedImportFlags()
      原因：20p / clementia / clone / dupBand 全是模块解析钩子方案（不是 content plugin），
            钩子没进子进程 = 该版本房间里整个 mod 不存在；lobby 层也不会拦
            （room.modded 只对 content plugin 为 true，两处 VERSION_UNSUPPORTED 不命中）
      影响范围：仅版本主机 fork 分支；默认版本走本进程，不受影响；
                forkSandbox 沙箱分支刻意不传（--permission 安全模型）
      合并策略：保留 inheritedImportFlags + fork 追加逻辑；上游若重写 host 的 fork 参数
                或改用 worker 启动，必须把同样的钩子传递接回去（否则 mod 在版本房间静默失效）
      验证：test/match/version-host.test.js 全文件 8 项测试通过，
            其中第 8 项为 inheritedImportFlags 的 9 组边界断言
